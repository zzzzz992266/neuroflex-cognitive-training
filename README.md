# NEUROFLEX · 认知训练场

一个纯静态、无后端、无构建步骤的 HTML5 认知训练游戏，可直接部署到 GitHub Pages。

## 训练模式

- **色卡冲突**：忽略文字含义，选择字体实际颜色
- **Go / No-Go**：Go 立即反应，No-Go 保持克制
- **找不同**：在程序生成的两幅 SVG 图形中寻找唯一差异
- **短时记忆**：记住图形序列并按顺序复现
- **弹珠舒尔特**：在数字弹珠盘中按顺序完成目标
- **综合训练**：五种玩法混合在一局，每种 3 题

## 核心规则

- 每个专项模式一局固定 15 题
- 综合训练一局同样是 15 题：五种玩法各 3 题，分三轮混合
- Level 1–4 全部开放，可在开局前选择
- 每个更高 Level 都会缩短时间或增加干扰
- 成绩、正确率和最佳分按“模式 + Level”分别保存在本机

## 模式细节

### 色卡冲突

玩家看到颜色词，但必须选择字体的实际颜色。Level 越高，时限越短，冲突题比例越高。

### Go / No-Go

Go 刺激出现时点击或按空格；No-Go 刺激出现时保持不动。Level 越高，反应窗口越短，No-Go 比例越高。

### 找不同

每一对图形由程序生成，只包含一处差异。点击正确区域进入下一题，错误点击会扣分。

### 短时记忆

先观看一组图形序列，再按相同顺序点击复现。Level 越高，序列越长、播放速度越快。

### 弹珠舒尔特

完成一个盘面算 1 题。每局共 15 个盘面，按顺序寻找目标数字，错误点击会扣分。

### 综合训练

每局 15 题，五种玩法各出现 3 次。三轮中每轮各包含五种玩法一次，轮内顺序随机。

## 技术结构

```text

├── index.html
├── styles.css
├── engine.js                  # 纯逻辑：关卡配置、题目生成、计分
├── game.js                    # 页面状态机、五种交互、计时器、音频
```

## 本地运行

```bash
cd "/Volumes/disc d/NBack Game"
python3 -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。

不要直接双击 `index.html`，浏览器会因 ES Module 安全策略阻止运行。

## 测试

```bash
node --test
```

测试覆盖：

- 五种专项模式和综合训练的题目生成
- 综合训练每种玩法出现 3 次
- Level 1–4 速度与难度单调递增
- 计分、连击和等级
- 色卡冲突、Go / No-Go、找不同、短时记忆和舒尔特的题目约束

## 部署

项目没有运行时依赖和构建步骤。推送到 GitHub 的 `main` 分支后：

1. 打开仓库 **Settings → Pages**；
2. 将 **Source** 设置为 **GitHub Actions**；
3. 已包含的 `Deploy static game to GitHub Pages` 工作流会自动发布。

## 说明

本项目是认知挑战游戏，不是医疗设备或临床评估工具。训练数据只保存在当前浏览器，不会上传。
